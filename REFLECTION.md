# Week 1 reflection
1. What is the difference between building a UI imperatively (plain DOM code) and
declaratively (React)?

imperative UI need to code each element of UI from scratch and step by step, while declarative UI uses components of UI thats templated in React making it simpler to use.

2. Why must a component name start with a capital letter?
So that it doesnt treat the component name as HTML tag

3. What does a fragment <>...</> do, and why not just use a <div>?
<div> works as a wrapper to divide a section in the layout and used as block elements. While <>...</> is used to group an element without wrapping it or affecting how the layout is in the page and are used to return multiple component as a single value.

4. Name one benefit of splitting the UI into small components.
More organized and easy to reuse.
